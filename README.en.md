FlowTrail turns profile information and question-to-answer mappings into browser tasks. Follow task status, inspect actions and screenshots, and open the browser for manual review. The current focus is Chinese questionnaire workflows, local demos, and browser-agent integration experiments.

## Features

- A Wenjuanxing entry point with URL and input validation.
- Structured profile information and explicit answer mappings.
- Task status, run details, screenshots, and browser access.
- Fill-only instructions by default, with an explicit submit option.
- Bailian OpenAI-compatible model configuration and registration.
- A local two-page questionnaire with fill, submit, and missing-information scenarios.

**Experimental:** submission behavior is controlled by model instructions, not an enforced browser action gate. Local fixture results do not establish compatibility or success rates across real questionnaires.

## Quick start

Requires Docker Compose 2.24.4+, Node.js 22+, Python 3.11+, and a vision-capable Bailian model API key.

```bash
git clone https://github.com/unumbrela/flowtrail.git
cd flowtrail
cp .env.example .env
cp .env.bailian.example .env.bailian
cp skyvern-frontend/.env.example skyvern-frontend/.env
```

Set your model key in `.env.bailian`. Remove the `VITE_SKYVERN_API_KEY=YOUR_API_KEY` placeholder from the frontend `.env`; the UI service reads credentials generated by the backend on first startup.

```bash
npm --prefix skyvern-frontend ci
npm --prefix skyvern-frontend run build
docker compose up -d
# Wait for the backend to become healthy in docker compose ps:
python3 scripts/setup_bailian.py
```

Open [the local workbench](http://localhost:8080/wenjuanxing). Model runs incur provider usage. The default deployment uses a pinned backend image; local backend source edits require a custom image build.
