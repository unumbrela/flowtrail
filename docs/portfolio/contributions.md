# FlowTrail 贡献与设计说明

## 本次二次开发范围

- 新增问卷星页面：链接白名单与输入约束、资料和答案映射、提交选项、任务状态、运行及浏览器入口。
- 新增任务生成器：将结构化输入转换为 Skyvern 请求，明确缺失信息、人工处理和问卷不可用三类终止条件。
- 接入现有浏览器会话与任务 API；启动期间禁用重复创建，失败时保留填写内容。
- 修正本地可选诊断接口的特定 403 被误报为身份失效的问题，真实鉴权错误仍正常报告。
- 调整工作台主题、导航、发现页与项目品牌，提供 FlowTrail 标识及来源入口。
- 提供固定镜像的本地部署配置、百炼模型注册、中文演示问卷与集成验证脚本。

以上是仓库相对上游基线的改动范围，不将上游引擎、SDK 或全部既有测试作为本项目原创成果。

## 请求路径与取舍

前端校验用户输入，生成任务指令；通过 `POST /v1/browser_sessions` 创建 60 分钟会话，再调用 `POST /v1/run/tasks`。上游 Agent 调用所选模型并操作浏览器。前端轮询任务状态，提供运行记录及浏览器入口。模型凭据由后端管理，填写内容进入任务记录。

复用上游执行器可以保留截图、运行历史和会话查看能力，避免引入第二套浏览器进程。代价是执行效果依赖模型和页面结构：默认不提交是指令约束，而不是动作级授权机制。更强的提交保护需要后端动作拦截与用户确认协议，当前未实现。

每次启动使用独立会话，避免复用已结束任务会话时遇到占用状态。任务创建失败不自动重试，以免重复创建；创建结果不明确时需要检查 Runs。

## 测试证据与限制

- 单元与组件测试覆盖 URL / 输入校验、任务生成、页面状态及鉴权诊断回归；命令见根 README。
- 本地集成测试覆盖入口、两页填写、文本、下拉、单选、多选与提交结果。
- 提交测试核对回执数量及字段；只填写测试核对无新增回执，并结合运行截图检查答案。
- 缺少必填邮箱时观察到 `MISSING_INFORMATION` 终止结果。
- 未验证真实问卷星的矩阵、评分、复杂联动及登录验证码处理；没有规模或成功率基准测试。
- 本机未安装 pre-commit，未完成上游全仓 pre-commit 检查。定向测试和生产构建不能替代全仓后端回归。

## 求职展示建议

可描述为：“基于 Skyvern 开发中文问卷自动化工作台，实现结构化资料到浏览器任务的转换、状态追踪和人工接管入口；通过本地多页问卷验证填写、提交与缺失信息终止流程。”

面试演示优先使用虚构资料和本地夹具，展示输入校验、模型执行记录、回执核对及失败处理，并说明上游复用部分与上述限制。
