# FlowTrail 路线图

这是候选开发方向，不是版本交付承诺。当前处于实验阶段。

## 已有能力

- [x] 中文问卷场景入口、链接校验、资料与答案映射。
- [x] 任务状态、运行详情和浏览器查看入口。
- [x] 默认只填写与显式提交的任务指令。
- [x] 百炼配置、固定镜像与本地问卷夹具。
- [x] 填写、提交、缺失信息的集成验证脚本。

## 优先补齐

- [ ] 浏览器动作层的提交确认与拦截机制。
- [ ] 更多真实题型的脱敏夹具：矩阵、评分、复杂联动。
- [x] 页面刷新后的运行状态恢复（保留运行引用，不持久化填写资料）。
- [x] 持久化幂等记录、内容冲突检测和未知创建结果的只读恢复。
- [x] 取消结果确认、终态会话释放和容器重启后的引用恢复。
- [ ] 更清晰的失败原因与恢复路径。
- [x] 版本化本地评测集、重复运行、源码哈希及逐次结果。
- [ ] 完整模型版本/用量快照与更广泛场景的公开基准。

## 后续探索

- [ ] 多模型配置与可比较的评测方法。
- [ ] 可复用的表单场景模板。
- [x] 白名单运行摘要导出，明确标注未独立核验。

首次贡献可以从文档排错说明、现有题型的边界测试、虚构资料夹具开始。先通过[贡献指南](../../CONTRIBUTING.md)说明场景和验收方法。
