# FlowTrail 路线图

这是候选开发方向，不是版本交付承诺。当前处于实验阶段。

## 已有能力

- [x] 中文问卷场景入口、链接校验、资料与答案映射。
- [x] 任务状态、运行详情和浏览器查看入口。
- [x] 默认只填写与显式提交的任务指令。
- [x] 百炼配置、固定镜像与本地问卷夹具。
- [x] 填写、提交、缺失信息的集成验证脚本。

## 优先补齐

- [ ] 浏览器动作层的提交确认与拦截机制。
- [ ] 更多真实题型的脱敏夹具：矩阵、评分、复杂联动。
- [ ] 页面刷新后的运行状态恢复。
- [ ] 更清晰的失败原因与恢复路径。
- [ ] 可公开复现的测试环境、模型配置和评测记录。

## 后续探索

- [ ] 多模型配置与可比较的评测方法。
- [ ] 可复用的表单场景模板。
- [ ] 脱敏的运行报告导出。

首次贡献可以从文档排错说明、现有题型的边界测试、虚构资料夹具开始。先通过[贡献指南](../../CONTRIBUTING.md)说明场景和验收方法。
